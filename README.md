# Project Overview

Developed an employee management dashboard that enables users to log in, view employee details, and perform add, edit, and delete operations. The dashboard also supports search, filtering, and print functionality for efficient data management.    

## Tech stack used

React, typescript

## Available Scripts

### `npm start`

Runs the app in the development mode.\
Open [http://localhost:3000](http://localhost:3000) to view it in your browser.
